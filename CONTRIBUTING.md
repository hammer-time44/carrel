# Contributing to Study Workspace

Thank you for contributing to Study Workspace!

## Development Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/study-workspace/study-workspace.git
   cd study-workspace
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development build:
   ```bash
   npm run build
   npm start
   ```

## Pull Request Guidelines
- Ensure all tests pass: `npm test`
- Ensure strict typecheck passes: `npm run typecheck`
- Ensure linting passes: `npm run lint`
- Write conventional commit messages (`feat: ...`, `fix: ...`, `docs: ...`).
