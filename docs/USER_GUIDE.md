# Study Workspace User Guide

## 1. Opening Study Materials
* **Drag and Drop:** Drag any PDF, Word (.docx), PowerPoint (.pptx), or Excel/CSV (.xlsx, .csv) file anywhere onto the Study Workspace window.
* **Open Dialog:** Click the `+` button on the tab bar, the document button on the left rail, or press `Ctrl` + `O`.
* **Recent Documents:** Access recently opened study files from the empty state screen or by pressing `Ctrl` + `K`.

---

## 2. Using the Document Viewers
* **Word Documents (.docx):**
  - Click anywhere to edit notes. Format with Bold (`Ctrl+B`), Italic (`Ctrl+I`), Underline (`Ctrl+U`), Heading 1, Heading 2, or Lists.
  - Press `Ctrl` + `S` to save directly back to the `.docx` file on disk.
* **Spreadsheets (.xlsx / .csv):**
  - Click any cell to view and edit its value in the formula bar.
  - Switch between sheets using the sheet selector tabs.
  - Press `Ctrl` + `S` to write changes back to the workbook.
* **PowerPoint Presentations (.pptx):**
  - Navigate slides using the left/right arrow keys or the thumbnail list.
  - Click **Present** or press `F5` for distraction-free fullscreen presentation mode.
  - Toggle **Speaker Notes** to review lecture commentary.
* **PDF Documents (.pdf):**
  - Use `Ctrl` + `+` and `Ctrl` + `-` to adjust zoom, or click **Fit** (`Ctrl+0`).
  - Search document text using the search bar in the PDF toolbar.
  - Select text and click **Highlight** to pin key study highlights to your sidecar.

---

## 3. Split View & Comparative Study
* To study lecture slides side-by-side with your study notes, click the **Split View** button in the top title bar or press `Ctrl` + `K` and select **Toggle Split View**.
* Drag the divider between panes to resize the view.

---

## 4. Spaced Repetition Flashcards
* Click **Flashcards** in the top title bar or left rail.
* Click **Start Review Session** to review due flashcards using the SM-2 algorithm:
  - **Again (1d):** Review again tomorrow if forgotten.
  - **Hard / Good / Easy:** Adjusts repetition intervals automatically.
* Create new custom cards at any time by clicking **Add Card**.
